# Internationalization (#24B2)

English is the source catalog. Flat, stable keys live in `src/locales/en.json`, `fr.json`, `de.json` and `es.json`. `src/lib/i18n.js` provides translation with English fallback, named interpolation, count plurals through `Intl.PluralRules`, and date/number formatting through `Intl`. Missing keys fall back to English; invalid locale codes use English. Technical values such as package names, Debian dependencies, paths, versions, refs, Run IDs and error codes pass through unchanged.

The language control in Settings > General updates the UI immediately. It stores `debBuilder24Locale` in localStorage; invalid values fall back to English. This is a browser preference, not a backend setting. English, French, German and Spanish all have the same 380 keys in #24B2. `npm run test:i18n` checks coverage, duplicate keys, placeholders, fallback, counts/formatting, technical values and component markup literals. Playwright checks all six pages at desktop/mobile sizes in all four locales for document overflow, with additional theme/locale screenshots. Backend-authored prose needs a deliberate translation boundary during #24C.

The separate public landing reuses the catalogs and formatter but reads browser language by default and stores its selector under `debBuilderPublicLocale`. It has no admin language or theme control dependency.
